💬 CHATWOOT_INTEGRATION
Chatwoot gives CloveH2O a live chat widget on the website, a shared inbox for customer support, sales, and product specialists — connected to n8n for automated responses.
STEP 1 · ADD TO DOCKER-COMPOSE

Once your Oracle/Hetzner server is live, add Chatwoot as a service. It runs on port 3000.

STEP 2 · EMBED ON CLOVEH2O.COM

Paste a single script tag into your Netlify site. The chat bubble appears immediately on every page.

DOCKER-COMPOSE SERVICE BLOCK
  chatwoot:
    image: chatwoot/chatwoot:latest
    container_name: sentaient_chatwoot
    restart: unless-stopped
    networks: [marketing_net]
    ports: ["3000:3000"]
    environment:
      - SECRET_KEY_BASE=${CHATWOOT_SECRET_KEY}
      - FRONTEND_URL=https://marketing.cloveh2o.com
      - DEFAULT_LOCALE=en
      - RAILS_ENV=production
      - POSTGRES_HOST=postgres
      - POSTGRES_USERNAME=chatwoot
      - POSTGRES_PASSWORD=${CHATWOOT_DB_PASSWORD}
      - POSTGRES_DATABASE=chatwoot
      - REDIS_URL=redis://redis:6379
    depends_on: [postgres, redis]
    volumes: [chatwoot_data:/app/storage]
NETLIFY EMBED SNIPPET (paste before </body>)
<script>
  (function(d,t) {
    var BASE_URL = "https://marketing.cloveh2o.com";
    var g=d.createElement(t),s=d.getElementsByTagName(t)[0];
    g.src=BASE_URL+"/packs/js/sdk.js";
    g.defer=true; g.async=true;
    s.parentNode.insertBefore(g,s);
    g.onload=function(){
      window.chatwootSDK.run({
        websiteToken: 'YOUR_WEBSITE_TOKEN',
        baseUrl: BASE_URL
      })
    }
  })(document,"script");
</script>
